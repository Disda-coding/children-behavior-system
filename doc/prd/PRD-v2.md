## 1. 产品概述

### 1.1 产品定位

面向现代家庭的**儿童行为管理与激励平台**：以积分为通货、以成就和奖励为驱动、以数据为反馈，帮助家长把"讲道理"变成"看得见的成长"，帮助孩子把"被要求"变成"我想要"。

按**多家庭产品**设计：支持多家庭注册、家庭隔离、成就/规则模板共享，具备后续推广能力。

### 1.2 一句话价值主张

- 对孩子：**像玩游戏一样养成好习惯** —— 每天回来合上进度的圆环、点亮徽章、攒分换奖励。
- 对家长：**像看 Apple 健康一样看孩子的成长** —— 数据清晰、操作简单、激励体系可定制。

### 1.3 设计参照

视觉与体验以 **Apple 健康 / Apple Watch** 为核心参照：

- 儿童端 = Apple Watch 的"活力感"：圆环、勋章、连续记录（Streak）、庆祝动效；
- 家长端 = Apple 健康的"精致数据感"：干净排版、克制配色、高质量图表。

## 2. 用户与场景

### 2.1 角色定义

| 角色         | 说明                | 核心诉求                |
| ---------- | ----------------- | ------------------- |
| 孩子（child）  | 家庭中的儿童成员，约 5-14 岁 | 即时反馈、成就感、收集欲、兑换奖励   |
| 家长（parent） | 家庭管理者，1-2 人       | 快速记录、规则定制、掌握趋势、审核裁决 |

### 2.2 核心场景

1. **日常记录**：孩子做完作业/表现好 → 家长一键加分（或扣分）→ 孩子端实时看到积分翻动、圆环前进。
2. **每日回归**：孩子打开 App → 看到今日圆环、Streak 火焰、可兑换的奖励 → 主动完成习惯任务。
3. **成就时刻**：达成成就 → 全屏庆祝动画（现有 Apple Watch 风格动画保留并升级）。
4. **兑换奖励**：孩子用积分兑换游戏时间/零花钱/实物 → 家长审核 → 完成兑现。
5. **争议仲裁**：孩子对扣分不服 → 提交申诉 → 家长审核并回复。
6. **家庭会议**：定期会议申请与评分，沉淀阶段性总结。
7. **周期复盘**：家长查看周报/趋势图，调整规则与奖励定价。

### 2.3 设备策略

**双端并重，完整响应式**：

- 移动端（≤768px）：孩子主要场景；底部 Tab 导航、大触控目标（≥44pt）、底部抽屉（Bottom Sheet）替代居中弹窗。
- 桌面端（>768px）：家长主要场景；左侧 Sidebar 导航、多列布局、悬浮弹窗。

## 4. 设计系统（Design System）

### 4.1 设计原则

1. **双主题，一套系统**：同一套设计令牌（Design Tokens）与组件库，通过主题变量派生儿童/家长两套皮肤。
2. **童趣不靠 emoji**：儿童端的趣味来自插画徽章、圆润造型、物理感动效，而非表情符号堆砌。
3. **数据要呼吸**：家长端借鉴 Apple 健康 —— 大数字、留白、克制的色彩、图表说话。
4. **动效即反馈**：所有关键状态变化（加分、升级、解锁、连续打卡）必须有动效确认，动效时长遵循"快入慢出庆祝"的节奏。

#### 4.2.4 图标体系

- **全面弃用 emoji 作为功能图标**。
- 线性图标：统一使用 Lucide（开源、圆头风格、两端通用）。
- 徽章/奖励图标：建立"徽章插画规范"——圆形底盘 + 金属质感渐变 + 中心符号，产出 SVG 组件 `AchievementBadge` 升级版，分 铜/银/金/铂金 四档质感。
- 空状态：统一插画式空状态组件（线条插画 + 一句话引导 + 主行动按钮）。

### 4.3 布局与导航架构

#### 4.3.1 应用外壳（AppShell）

新建统一 `AppShell` 布局组件，替代每页手写导航：

**儿童端**

- 移动端：底部 Tab Bar（首页 · 成就 · 奖励 · 我的），当前项有胶囊高亮 + 弹性动画；积分余额常驻 Tab Bar 上方迷你条。
- 桌面端：左侧窄图标栏（72px）+ 内容区居中（max-w-5xl）。
- 页面转场：移动端 slide、桌面端 fade，150-200ms。

**家长端**

- 桌面端：左侧 Sidebar（240px，可折叠至图标栏），分组导航：总览（仪表盘/统计）、激励（积分规则/成就/奖励）、事务（申诉/会议）、系统（日志/备份/设置）。
- 移动端：底部 Tab（总览 · 记录 · 审核 · 我的），低频页面收进"我的"。
- 顶部栏：面包屑 + 全局搜索（找孩子/找记录）+ 通知中心 + 头像。

### 6.4 奖励兑换 🔨（补完，当前 30%）

**兑换流程**

1. 孩子在奖励商城选择奖励 → 兑换确认弹层（显示余额、扣减后余额、库存）。
2. 生成兑换单（pending）→ 家长收到通知 → 审核通过/拒绝（可填原因）。
3. 通过后状态 → approved → 家长线下兑现后标记 completed；拒绝则积分自动退回。

**定价与库存**

- 普通奖励：固定积分价 + 可选库存（兑完自动置灰）。
- 游戏时间类：阶梯价 `cost(h) = 200 × 2^(h-1)`，在奖励配置 `config` JSON 中可改底价与倍率。
- 现金兑换：启用现有 `exchange_rates` 表，孩子可将积分按家庭汇率换零花钱（产生 type=convert 记录，家长审核）。

**家长管理端**：奖励 CRUD、上下架、库存调整、定价编辑、兑换审核列表（待审红点提醒）。

### 6.5 申诉系统 🆕

### 6.7 游戏化增强 🆕（本版重点新增）

#### 6.7.1 每日圆环（Daily Rings）

首页核心视觉，三环含义：

| 环   | 颜色  | 含义             | 目标来源                     |
| --- | --- | -------------- | ------------------------ |
| 积分环 | 珊瑚红 | 今日获得积分 / 今日目标  | 家庭设置（默认 50 分/天）          |
| 习惯环 | 嫩芽绿 | 今日好习惯打卡次数 / 目标 | 规则中标记"日常习惯"的完成次数（默认 3 次） |
| 坚持环 | 晴空青 | 本周达标天数 / 7     | 系统计算                     |

三环全合 → 当日"完美一天"庆祝动效 + Streak 计数。

#### 6.7.2 连续打卡（Streak）

- 定义：当日积分环闭合（达到日目标）即记 1 天连续。
- 展示：首页 StreakFlame 火焰 + 当前/历史最佳连续天数。
- **冻结卡**：每月赠 2 张，断签日自动消耗 1 张保住 Streak（库存为 0 则清零）。
- 里程碑：7 / 30 / 100 天触发特殊徽章与庆祝。

#### 6.7.3 等级体系

- 经验值 EXP = 累计获得积分数（扣分不回扣 EXP）。
- 等级称号（可配置）：萌芽 → 新叶 → 小树 → 繁星 → 皓月 → 骄阳（L1-L6），每级所需 EXP 阶梯增长。
- 升级触发升级动效；等级展示于孩子头像框与家长端孩子卡片。

## 7. 页面改版详案（关键页面线框描述）

### 7.1 登录页

- 桌面端左右分栏：左 45% 品牌区（渐变底 + Logo + 产品 slogan + 圆环插画动效），右侧表单卡片；移动端单列顶部品牌。
- 登录后按角色进入对应主题。

### 7.2 儿童端首页（改版核心）

自上而下：

1. **问候条**："早上好，小明"+ 日期；右侧 Streak 火焰（当前连续 N 天）。
2. **今日三环卡**（视觉焦点）：大号 RingProgress 三环 + 环下数据标签；全合时触发庆祝。
3. **积分卡**：FlipNumber 大数字 + 今日 +N；点击进积分记录。
4. **今日任务速览**：家庭设定的"日常习惯"规则列表，完成打勾样式（只读展示，实际加分仍由家长操作）。
5. **想去兑换**：积分够得着的最近 3 个奖励（"再攒 20 分即可兑换游戏机 1 小时"的进度条）。
6. **最近动态**：正负分流水。

### 7.3 家长端仪表盘

1. 顶部统计条：家庭今日加分次数、待审核数（红点）、本周活跃天数。
2. **孩子卡片**（每孩一张）：头像+等级框、余额、今日三环迷你版、Streak、快捷加减分按钮、待办入口。
3. 待办队列：待审兑换/申诉/会议申请，一键跳转处理。
